タイトル背景の写真を置くフォルダ（ChatGPT で生成した画像を webp にして、この名前で置く）
置いたらアプリを再起動するだけで表示される。置いていない画像は、今までの山とテントの絵のまま。

home.webp      ホーム（大きな見出しの背景）
list.webp      計画一覧
form.webp      新しい計画をつくる・計画を編集する
detail.webp    計画詳細
products.webp  DEPO商品一覧・お店の商品を選ぶ
help.webp      マイページ・使い方ガイド・よくある質問
admin.webp     管理者ページ

しおり・思い出のページの写真（種類ごと。枠つきの写真として表示）は、1つ上の images フォルダに置く：
camp.jpg（キャンプ）、travel.jpg（旅行）、picnic.jpg（ピクニック）

おすすめの大きさ：横 1536 × 縦 1024（3:2）。300KB 以下が目安。
写真の左側に文字が重なるので、主役（テントなど）は右半分・上下のまん中あたりに入れる。
